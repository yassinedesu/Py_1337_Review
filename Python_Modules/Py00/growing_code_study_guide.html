1. Functions (Exercise 0)

Defining vs calling

  • Defining uses def: it creates the function but runs nothing.
  • Calling uses the name followed by parentheses: it executes the body.
def greet():              # definition: nothing is printed yet
    print("Hello")

greet()                   # call: now it runs

What do the parentheses mean?

The parentheses hold the parameters. Empty parentheses () mean the function takes no parameters at all.

def no_params():            # takes 0 arguments
    ...

def with_default(name="x"): # optional parameter (has a default)
    ...
What happens if you pass an argument to a zero-parameter function? Python raises a TypeError: ft_hello_garden() takes 0 positional arguments but 1 was given.

2. print() & expressions

print() writes what you give it to stdout (your terminal) as text.

A string alone on a line

A bare "Hello" inside a function is an expression statement: Python evaluates it, gets a value, and since nothing stores or uses that value, it is immediately discarded. Nothing is displayed.

The docstring special case

If a string literal is the very first statement of a function, it becomes the function's docstring (documentation). Anywhere else (middle, end) it is just a discarded expression.

def ft_hello_garden():
    "Greets the garden community"   # docstring (first statement)
    print("Hello, Garden Community!")
    "I am just a discarded expression"  # not a docstring

3. input() & strings (Exercises 1 & 2)

input(prompt) shows the prompt, waits for the user, and always returns a str, whatever the user types.

x = input("Enter: ")   # user types 5
type(x)                # <class 'str'>   (it is "5", not 5)
Why it matters Strings cannot be multiplied together. Doing arithmetic on raw input() results crashes with a TypeError. Convert first. 
length = int(input("Enter length: "))   # str -> int
name = input("Enter name: ")            # already a str, no str() needed

Wrapping input() in str() is redundant: it already returns a string.

Conversion functions: int(), float(), str(), bool().

5. Variables & evaluation order (Exercise 3)

A variable is a name that refers to a value.

name = "user"
number = 19

Step by step: summing three harvests

total = int(input("Day 1 harvest: ")) + int(input("Day 2 harvest: ")) + int(input("Day 3 harvest: "))
  1. First input() runs, user types, result converted with int().
  2. Second input() runs, converted with int().
  3. Third input() runs, converted with int().
  4. The three integers are added together.
  5. The sum is stored in total.

Evaluation goes left to right, and each int() conversion happens on each value individually before the addition.

6. if / else & booleans (Exercises 4 & 5)

A comparison expression evaluates to a bool, and if uses that boolean to choose a branch.

age = 75
age > 60        # evaluates to True  (type: bool, NOT int)

if age > 60:
    ...           # runs when True
else:
    ...           # runs when False
OperatorMeaning
>Strictly greater than
>=Greater than or equal to
< / <=Strictly less / less or equal
== / !=Equal / not equal
Boundary values matter Exercise 4 says "strictly more than 60", so > is required. A plant exactly 60 days old is not ready (>= would wrongly accept it). Exercise 5 follows the same logic with "more than 2 days".

7. for loops & range() (Exercise 6, iterative)

A for loop is an iteration construct: it repeats a block once for each element of a sequence. (The condition-driven loop is while.)

range(start, stop) produces numbers from start up to stop - 1 (stop is excluded).

for i in range(1, 4):
    print(i)
# prints 1, 2, 3  (not 4)

To count to n inclusive, use range(1, n + 1).

8. Recursion (Exercise 6, recursive)

A recursive function calls itself. Two ingredients are essential:

  1. Base case: a condition that stops the recursion.
  2. Recursive call: the function calling itself on a smaller/closer problem.
No base case? The function keeps calling itself until the call stack is exhausted: RecursionError: maximum recursion depth exceeded.

Illustration on a different problem (countdown):

def countdown(n):
    if n == 0:          # base case
        return
    print(n)
    countdown(n - 1)    # recursive call, closer to the base case

Acceptable approaches for exercise 6: a nested helper function, default parameter values, or a separate helper function. Both versions must produce identical output.
