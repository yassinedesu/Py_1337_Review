Correct definition: Overriding is when a subclass redefines a method it inherited from its parent, replacing the parent's behavior with its own.

Duck Typing vs Protocol — conflated ✗ CONFLATED
You described Protocol when asked about duck typing. They are related but distinct.

Duck typing is Python's general runtime philosophy — "if the object has the method, just call it, don't check its type." It predates Protocol and requires no import.

Protocol is how mypy formalizes duck typing statically — the type checker verifies the shape without requiring inheritance.

Also: what CSVExportPlugin does is not overriding. It never inherits from ExportPlugin, so there is nothing to override. It simply independently implements a method with the matching signature.
