Exercise 0: Entering the Matrix

File: construct.py · Allowed: sys, os, site, print()

1. Why virtual environments exist

A virtual environment is an isolated bubble with its own Python and its own installed packages, so projects don't interfere with each other.

Without a venv (global install)With a venv per project
Project A needs pandas 1.0, Project B needs pandas 2.0. One of them breaks. Each project has its own pandas version. No conflicts.
Everything you install pollutes the system Python.The global Python stays clean.

2. How creating and activating works

python3 -m venv matrix_env          # create the venv (a folder)
source matrix_env/bin/activate      # activate it (Linux/macOS)
matrix_env\Scripts\activate         # activate it (Windows)
deactivate                          # leave the venv
What activation really does Activation prepends the venv's bin/ folder to your PATH. When you type python3, the shell searches PATH from left to right, so it now finds the venv's Python first instead of /usr/bin/python3.
The (matrix_env) text in your prompt is only a visual hint ("cosmetic"). The PATH change is the real mechanism. Activation also sets the variable VIRTUAL_ENV. 
which python3        # before -> /usr/bin/python3
source matrix_env/bin/activate
which python3        # after  -> /path/to/matrix_env/bin/python3
Do not submit your venv Never commit the venv folder to git. You must be able to recreate it during review.

3. Detecting a venv from Python

import sys

sys.prefix        # where the CURRENT Python lives
sys.base_prefix   # where the ORIGINAL global Python lives

if sys.prefix != sys.base_prefix:
    print("Inside a virtual environment")
else:
    print("Global environment")
Situationsys.prefixsys.base_prefixResult
Global/usr/usrEqual → not in venv
Inside venv/path/to/matrix_env/usrDifferent → in venv

Good to know VIRTUAL_ENV is a standard name set automatically by the activate script. You never create it yourself. .get() returns None instead of crashing when the variable doesn't exist.
sys.prefix vs sys.executable sys.prefix is a folder; sys.executable is the python file. The expected output of the subject shows Current Python: .../bin/python, which matches sys.executable.

1. pip vs Poetry

pipPoetry
RoleJust an installerFull project and dependency manager
Tracks dependenciesYou maintain requirements.txt by handUpdates pyproject.toml automatically
Creates a venvNo (you do it)Yes, automatically
Locks exact versionsNoYes, in poetry.lock
Install commandpip install -r requirements.txtpoetry install
Run commandpython3 loading.pypoetry run python loading.py
About the apt/aptitude analogy It is close but not exact. The key point is: pip installs; Poetry manages the whole project (environment, dependencies, versions, lock file).
poetry add pandas      # installs AND records it in pyproject.toml
poetry install         # installs everything listed in pyproject.toml

3. importlib: handling missing dependencies

The subject requires the program to handle missing packages gracefully, with a helpful message instead of a crash.

import importlib.util

def check_package(name: str) -> bool:
    spec = importlib.util.find_spec(name)   # None = not installed
    if spec is None:
        print(f"[MISSING] {name} - run: pip install {name}")
        return False
    return True

find_spec() only checks whether the package exists, without importing it.

find_spec vs try/except import find_spec is a clean check with no side effects (the package isn't executed or loaded). It lets you list all missing packages up front, then print install instructions for both pip and Poetry.

5. How a PNG comes out of a Python script

  1. Check dependencies with importlib. If any is missing, print instructions and stop.
  2. Generate data with numpy (time values + noisy wave).
  3. Structure it with pd.DataFrame into time and signal columns.
  4. Smooth it with .rolling(20).mean().
  5. Plot and save with matplotlib: savefig("matrix_analysis.png").
import numpy as np
import pandas as pd
import matplotlib
matplotlib.use("Agg")             # render to files, no window needed
import matplotlib.pyplot as plt

time_values = np.linspace(0, 4 * np.pi, 1000)
noise = np.random.normal(0, 0.3, 1000)
signal_values = np.sin(time_values) + noise

data_frame = pd.DataFrame({"time": time_values, "signal": signal_values})
smoothed = data_frame["signal"].rolling(window=20).mean()

figure, axis = plt.subplots(figsize=(10, 4))
axis.plot(data_frame["time"], data_frame["signal"], alpha=0.4, color="green", linewidth=0.6, label="Raw signal")
axis.plot(data_frame["time"], smoothed, color="lime", linewidth=2, label="Smoothed signal")
axis.set_title("Matrix Signal Analysis")
axis.legend()
figure.savefig("matrix_analysis.png", dpi=100, bbox_inches="tight")
plt.close(figure)

6. Every function explained

dict.get(key, default) 
package_descriptions.get(package, "Ready")
  • Parameter 1: the key to look up.
  • Parameter 2: the value returned if the key doesn't exist (default is None).
  • Works on dictionaries (and dict-like objects such as os.environ).
np.linspace(start, stop, count) 
np.linspace(0, 10, 5)   # [0, 2.5, 5, 7.5, 10]
  • start, stop (both included), and count of numbers.
  • The spacing is always equal. For 0 to 4π with 1000 points, each step is about 0.0126.
  • Here it builds the time axis.
np.sin(x): what is a sine?

Forget the maths: sin turns a list of numbers into a smooth repeating wave that goes up to +1, down to -1, and repeats.

  1 |  *   *
    | * * * *
  0 |*       *       *
    |         * * * *
 -1 |          *   *

4 * np.pi covers 2 full wave cycles (one cycle = 2π).

np.random.normal(mean, std, count): the noise
  • 0 (mean): the centre the numbers cluster around.
  • 0.3 (standard deviation): how spread out they are.
  • count: how many numbers.
Common misunderstanding 0.3 is not a hard maximum. Values can exceed it, but most (about 68%) fall between -0.3 and +0.3.

sin(time) + noise = a clean wave plus random mess = a realistic signal.

.rolling(window=20).mean(): moving average

Look at 20 points at a time, average them, slide forward by 1, repeat. The result is a smoother line that keeps the trend and drops the jitter.

raw:       [1, 5, 2, 8, 3, 6, 4, 7 ...]
window=3:  [avg(1,5,2), avg(5,2,8), avg(2,8,3) ...]
result:    [2.7, 5.0, 4.3 ...]
  • .rolling(window=20): defines the sliding group size.
  • .mean(): what to compute for each group (the average).
  • The first 19 values are NaN because there aren't 20 points yet.

Likely peer-review questions

Why use a virtual environment?To avoid dependency conflicts between projects and keep the global Python clean.
What does activate actually change?It puts the venv's bin/ at the front of PATH (and sets VIRTUAL_ENV), so python and pip resolve to the venv's copies.
How does your script detect a venv?It compares sys.prefix with sys.base_prefix; if they differ, it is running inside a venv.
pip vs Poetry?pip only installs packages. Poetry also creates the environment, records dependencies in pyproject.toml, and pins exact versions in poetry.lock.
Why does your numpy data matter?The subject requires the dataset to come from numpy, not hardcoded lists or range().
What does ^2.1.0 allow?Any compatible version from 2.1.0 up to, but not including, 3.0.0.
Why is .env in .gitignore?It holds real secrets; once committed they stay in git history and can leak. .env.example is committed instead as a safe template.
